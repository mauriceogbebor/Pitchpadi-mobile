# PitchPadi app

One Android and iOS app for PitchPadi:

- **Play** is for players: find an open 5-a-side or 7-a-side pitch in Lagos, book it and pay.
- **Venue** is for owners and staff: the day's bookings, adding phone and walk-in bookings, and hours and prices.

The app is built with Expo (SDK 58), expo-router and TypeScript. It talks to the same API as the website (`pitchpadi-api`), through a client generated from the API's `openapi.json`. Every business rule (prices, slots, holds, payments) lives in the API, not here. See ADR-003 in `pitchpadi-fe/docs/tech/adr/`.

Status: **M0 (foundation)**. Sign-in, Play search and a read-only Venue calendar work. Booking from the app comes in M1. The phases are listed in `pitchpadi-fe/docs/product/BACKLOG.md` under "Mobile app (E-11)".

## Run it on your phone

You need Node 22, the API running on your Mac, and the free **Expo Go** app on your phone (Play Store or App Store). The phone and the Mac must be on the same Wi-Fi.

1. Start the API on your Mac (in `pitchpadi-api`):

   ```bash
   npm run dev
   ```

   It listens on port 4000.

2. Find your Mac's address on the Wi-Fi:

   ```bash
   ipconfig getifaddr en0
   ```

   For example `192.168.1.23`.

3. Install and start the app (in `pitchpadi-mobile`):

   ```bash
   npm install
   EXPO_PUBLIC_API_URL=http://192.168.1.23:4000 npx expo start
   ```

4. Scan the QR code:
   - On Android, scan it from inside Expo Go.
   - On iPhone, scan it with the Camera app.

5. Sign in with an owner from the development seed, for example `0703 000 1000`. Until SMS is connected, the code is shown on screen.

Without `EXPO_PUBLIC_API_URL`, the app uses the Mac running `expo start` on port 4000, which is usually right too.

If the phone cannot reach the API:

- check that the Mac's firewall allows incoming connections for Node;
- try `npx expo start --tunnel` (the API address must still be reachable from the phone).

## Commands

| Command                  | What it does                                                                   |
| ------------------------ | ------------------------------------------------------------------------------ |
| `npx expo start`         | Start the development server (press `a` for an Android emulator, `w` for web). |
| `npm run lint`           | ESLint (Expo rules).                                                           |
| `npm run typecheck`      | TypeScript, strict.                                                            |
| `npm test`               | Unit tests for the formatting helpers (Node's test runner).                    |
| `npm run format`         | Prettier.                                                                      |
| `npm run api:sync`       | Copy `openapi.json` from the API and regenerate `src/api/generated.ts`.        |
| `npm run api:check`      | Fail if the generated client is out of date.                                   |
| `npx expo install <pkg>` | Add a library at the version that matches the Expo SDK. Use this, not `npm i`. |

`api:sync` reads the API from `../pitchpadi-api` by default. Set `OPENAPI_SOURCE` to use another path.

## How it is put together

```
src/
  app/                 screens (expo-router: every file is a route)
    _layout.tsx        fonts, splash, data cache, sign-in state
    (tabs)/            Play, Venue (shown only to venue members), Account
    sign-in.tsx        phone number, then the 6-digit code
  api/
    generated.ts       generated by orval: never edit by hand
    fetch.ts           adds the session token; signs out on 401
    config.ts          where the API is
  auth/                session token in the phone's secure storage; sign-in state
  components/ui.tsx    Screen, Heading, Body, Button, Field, Card, Notice, Skeleton
  theme/               colours (light and dark), fonts, spacing
  lib/format.ts        naira, Lagos times and dates, phone numbers
tests/                 unit tests
```

**Sign-in.**

- The app asks the API for a session token (`client: "app"` on verify), keeps it in the Keychain or Keystore through `expo-secure-store`, and sends it as `Authorization: Bearer`.
- A 401 clears the token and returns the app to signed out.
- The website keeps using cookies.

**Lagos time.** Lagos is UTC+1 all year. `lib/format.ts` does the arithmetic itself instead of relying on the phone's time zone data, which differs between Android phones.

**Data.**

- React Query caches responses for 30 seconds and retries twice, so a flaky connection does not blank the screen.
- Pull down to refresh.

## Builds and releases

Store builds use EAS (`npx eas-cli@latest build`) and need PitchPadi's Apple and Google developer accounts (M5). Over-the-air updates (`eas update`) can ship JavaScript-only fixes without a store review.
